# F1ライン分析

競輪F1戦の「ライン・番組・S（前受け）」と結果・配当の関係を集計し、当日のレースに当てはめるアプリです。
データは楽天Kドリームスの公開ページから取得します（個人利用の範囲で、1秒に1ページずつ読みます）。

## 必要なもの
- Python 3.10 以上（https://www.python.org/ からインストール。Windows はインストール時に「Add python.exe to PATH」にチェック）

## 起動
- Windows：`start.bat` をダブルクリック
- Mac：`start.command` をダブルクリック（初回は右クリック→開く）

ブラウザで http://localhost:5000 が開きます。閉じるときは黒い画面（ターミナル）を閉じます。

## 最初にやること：過去データの取り込み
1. 「データ」タブで期間を選んで「この期間を取り込む」（初期値は過去1年）
2. 1か月分でおよそ15〜25分、1年分だと数時間かかります。途中で止めても、次回は取得済みを飛ばして続きから取ります
   - まず1〜2か月分で試して、慣れてから期間を広げるのがおすすめです
   - コマンドでも取り込めます：`.venv\Scripts\python store.py --from 2025-12-01 --to 2026-11-25`
3. 毎日の更新は右上の「最新の結果を取り込む」を押すだけ（最後に取り込んだ日から今日まで）

## 画面
- **当日予想**：日付を選んで「F1の出走表を読み込む」→ レースを選ぶ → Sを取りそうなラインをクリック  
  同じ型の過去レースから、ラインごとの1着率・3着内率、2車単の参考、多い展開パターン、万車券になる展開、該当レースへのリンクを表示します。  
  「各ラインがSを取った場合」の比較表もあります。並びが出ていないときは「並びを手入力する」から入力できます。
- **傾向分析**：級・番組・ライン区分・並びの形・競輪場で絞り込んで、Sライン／◎○ライン／⑥と最低得点選手／決まり手／番組別の万車券率などを集計
- **競輪場比較**：場ごとの差（全場平均から±8ポイント以上を色付け）

## 用語・判定のルール
- S／B：Kドリームスの結果表のS・B。S選手のラインを「Sライン」、B選手のラインを「主導権ライン」
- 並び：Kドリームスの「並び予想」（実際の周回と違う場合あり）
- ◎○▲：Kドリームス（アオケイ記者）の予想印
- ライン区分（7車）：三分戦＝2車以上のラインが3つ／二分戦＝2つ（単騎0〜1）／二分戦コマ切れ＝2つ＋単騎2以上／その他＝1つ／超コマ切れ＝それ以外
- 周長：333m（前橋335m含む：前橋・松戸・小田原・伊東・富山・奈良・防府）／500m（宇都宮・大宮・高知）／400m（それ以外）
- 当日予想の照合は「同じ周長」が初期表示（「この場」「全場」に切り替え可）。級は S級→S級だけ、A級→A級だけ（チャレンジ・ガールズもそれぞれだけ）
- 照合：並びの形・印・番組まで一致 → 番組問わず → 形のみ → ライン区分 → ライン区分＋Sの車数のみ、と20件以上になるまで条件をゆるめます

## ファイル
- `kd_scraper.py`：Kドリームスのページ読み取り
- `store.py`：取り込みと保存（`data/keirin.sqlite3`）
- `analysis.py`：分析ロジック。ここを変えると再起動だけで全レースに反映（再取得不要）
- `app.py` / `static/index.html`：画面

## スマホ用ページ（GitHubで自動更新）
- `.github/workflows/update.yml`：毎朝6:15・毎晩21:10・22:30（日本時間）に結果を取り込み、今日・明日のF1全レースを分析してページを書き出す
- `.github/workflows/backfill.yml`：1日6回、1回100分ずつ過去の結果をさかのぼって取り込む（初期設定は1年前まで。リポジトリの Variables に `BACKFILL_SINCE=YYYY-MM-DD` を入れると変更可）
- 取り込んだ結果は `races/年/月/日.jsonl` に保存（GitHubに記録）
- ページ：`https://<ユーザー名>.github.io/<リポジトリ名>/`

PCのアプリとデータを共有したいとき：
- PC → GitHub：`python store.py dump` で `races/` に書き出してアップロード
- GitHub → PC：`races/` をダウンロードして `python store.py load`

## 追加データ（netkeirin）
- netkeirin（keirin.netkeiba.com）の出走表から、選手ID と 直近4か月の S・H・B・逃げ・捲り・差し・マーク回数を取り込みます（`nk_scraper.py`）
- 先頭タイプ（先行型・先行型(叩かれ)・捲り型・自在型・追込型）の境目は `analysis.py` の `leader_type` で調整できます
- 取り込み済みのレースには「過去データの取り込み」が少しずつ値を足します

## メモ（notes/）
- 競輪場の特徴：`notes/venues/<競輪場名>.md`、選手のS評価とメモ：`notes/riders/<選手キー>.md`
- スマホのページの「書き込む」からGitHubの編集画面が開きます。保存すると「メモの反映」が動き、数分でページに出ます
